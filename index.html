OnlyHumans

Peer-to-peer encrypted chat. No message servers — only an address hub.

How it works

Your identity is a keypair generated on your device. The only shared service is this address hub: a signed, expiring {peer → address} directory. Messages travel directly between users; the conversation initiator hosts the room, mints its random room key, and can rotate it at any time — each new key is shared only with current participants, encrypted under the key in use.

Download

OnlyHumans 0.1.0 for Windows (64-bit installer, ~5 MB). Windows 10/11 with WebView2 (included by default). Run it, copy your ID from the app's header, and share it with the person you want to chat with — they enter your ID (or you theirs) and one of you clicks Chat.

Test build for multi-machine trials. Your identity and messages never leave your device; this site only ever holds signed, expiring IP addresses.

Status

Early development (M3 field trials). The hub API lives at /api/reg and /api/lookup/<peerId>.
