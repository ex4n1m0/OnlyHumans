Security, without the sales pitch.

OnlyHumans protects message content and room phrases. It does not pretend to erase every trace of communication.

✔ Protected
  • Message content is encrypted on your device.
  • Each message receives its own encryption key.
  • Messages are padded to reduce what message length can reveal.
  • Room keys are sealed individually for members.
  • Identity keys remain on the user's device.
  • Private chats can be memory-only and disappear when both people leave.
  • Network interception reveals encrypted data, not readable chat content.
◐ Visible to the hub
  • Peer identifiers and current network addresses, signed by the peer and expiring.
  • Which peer is currently hosting a room.
  • A random anonymous online token per session.
  • For fallback mail: encrypted envelope timing, size, and sender/recipient identifiers.
  • The hub cannot read message content or room phrases.
  • The hub cannot forge valid peer records.
✕ Honest limits
  • Malware or a compromised device can read what is visible on that device.
  • Guessable room phrases are not appropriate for private conversations.
  • Global traffic-analysis resistance is not implemented.
  • Browser clients use browser storage and are weaker than the signed Windows application.
  • The service cannot introduce new peers when the hub is unavailable, although already-connected peers may continue talking.

Questions people actually ask.

Do I need an account?

No. Choose a name and enter a room phrase. Your device creates a local identity key the first time you use OnlyHumans.

How do I create a room?

Enter any shared phrase to open its room, or generate a new multi-word phrase for a room you want to share privately. Anyone using the exact same phrase and compatible app version can find the same space.

Who can join my room?

Anyone who knows the exact room phrase and uses the matching version can find the same room. For private conversations, create and share a generated phrase that is hard to guess.

Where do my messages live?

Room history is kept on members' devices. The site does not store readable chat messages. Private chats can remain memory-only and disappear when both people leave.

What happens when someone is offline?

When direct delivery is unavailable, a sealed message can wait in the site mailbox and arrive after the recipient returns. The site still cannot read it.

Do we need the same version?

Yes. Each release is its own room, so people on different versions cannot see each other. Keep your app updated to meet people using the latest release.

Can I use it without installing anything?

Yes. Open the browser portal to join from any modern browser. It is ideal for convenience and casual rooms; use the Windows app for stronger local storage and the best performance.

Does it work on phones?

Yes, through the browser portal. The Windows desktop app is the full native application experience.
